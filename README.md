**Pasar Rempah** — a spice-auction card game set in a Nusantara port market. Over nine rounds you blind-bid against two rival merchants with learnable habits — Haji Karim, aggressive and fond of bluffing, and Nyonya Lie, a patient set-collector — for lots of nutmeg, cloves, pepper and cinnamon. A market card doubles one spice each round and stamps the cards you win with it ×2 forever; a tied top bid rolls the whole lot into the next round's pile; a complete set of all four spices pays a +12 bonus. Coins left plus warehouse value decide the richest trader at the final tally. Title screen, how-to screen, a labelled standings panel, quipping rivals, a brass balance, spice sacks, and win/lose tally screens — all drawn in code, fully offline.

## Run it

```sh
node main.ts
```

That copies the game to `/output` (or `$MAKEFUN_OUTPUT_DIR`) and writes the dossier. To play, serve the `game/` folder with any static file server and open `index.html` — it runs fully offline in a desktop browser, keyboard and mouse.
